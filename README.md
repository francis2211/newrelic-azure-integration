# New Relic Azure Integration

This repository contains the code and resources for integrating Azure services with New Relic.  It provides a streamlined way to monitor your Azure infrastructure and applications within the New Relic platform, offering valuable insights into performance, availability, and resource utilization.

## Features

* **Comprehensive Monitoring:** Collect metrics from various Azure services, including (but not limited to):
    * Virtual Machines
    * App Services
    * SQL Databases
    * Storage Accounts
    * Service Bus
    * Event Hubs
* **Automated Instrumentation:**  Simplify the integration process with tools and scripts for easy deployment and configuration.
* **Customizable Dashboards:** Create tailored dashboards in New Relic to visualize the specific metrics that are most important to your team.
* **Alerting and Notifications:** Configure alerts based on key performance indicators (KPIs) to proactively address potential issues.
* **Improved Observability:** Gain a unified view of your Azure environment and application performance, enabling faster troubleshooting and optimization.

## Getting Started

### Prerequisites

* A New Relic account (you can sign up for a free trial at [https://newrelic.com/](https://newrelic.com/))
* An Azure subscription
* Appropriate Azure permissions to create resources and access monitoring data
* [Optional] Azure CLI or PowerShell for scripting and automation
